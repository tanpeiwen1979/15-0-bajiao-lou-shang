# 15 八角楼上

小学语文二年级上册第六单元课文《八角楼上》的教学资源包。

## 课文简介

《八角楼上》讲述了在井冈山艰苦斗争的年代，毛主席住在茅坪村的八角楼，在寒冬腊月的深夜里，就着一盏清油灯写下许多光辉著作的故事。通过描写毛主席工作的艰苦环境和专注神态，展现了伟人在艰苦岁月中为中国革命不懈奋斗的精神。

课文全文：

> 在井冈山艰苦斗争的年代，毛主席住在茅坪村的八角楼。
> 每当夜幕降临的时候，八角楼上的灯就亮了。
> 这是个寒冬腊月的深夜，毛主席穿着单军衣，披着薄毯子，坐在竹椅上写文章。
> 他右手握着笔，左手轻轻拨了拨灯芯，灯光更加明亮了。
> 凝视着这星星之火，毛主席在沉思，连毯子滑落下来也没有察觉到。
> 就在这盏清油灯下，毛主席写下了许多光辉著作，照亮了中国革命胜利的道路。
